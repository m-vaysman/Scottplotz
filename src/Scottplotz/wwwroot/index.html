Scottplotz

Scottplotz is based on ScottPlot. This service is a thin REST API on top of the ScottPlot DLL, and the charts it returns are only a small sample of what ScottPlot can produce. Authorship belongs to ScottPlot (MIT license, copyright 2018 Scott Harden / Harden Technologies, LLC).

Paste numbers, columns, rows, or CSV. Render draws the PNG. Explain shows which rule fired.
